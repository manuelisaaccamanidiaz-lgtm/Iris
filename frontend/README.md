# Iris · Frontend

App web de Iris en React 19 + Vite 8, instalable como PWA. Toda la documentación del proyecto (puesta en marcha, HTTPS, variables de entorno y arquitectura) está en el [README principal](../README.md).

```powershell
npm install
npm run dev     # https://localhost:5173 (requiere los certificados de mkcert en ../certs)
npm run lint    # oxlint
npm run build   # versión de producción en dist/
```
